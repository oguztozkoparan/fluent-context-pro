Designing calm interfaces

6 min read · Interaction design

Good software gets out of the way. Menus should appear exactly where your attention already is, speak the visual language of your system, and disappear the moment you are done.

A familiar menu is one you never have to think about: the same shortcuts, the same motion, the same materials as the rest of the platform.

Read the complete guide to context menus for patterns that work on Windows, macOS and Linux alike.
