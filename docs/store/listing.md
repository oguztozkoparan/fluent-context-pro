## English

**Name:** FluentContext Pro

**Summary (≤132):** A fast, customizable right-click menu that looks native on Windows, macOS and Linux. Copy, search, translate and more.

**Description:**

FluentContext Pro replaces the browser's right-click menu with a clean, fast menu that matches your operating system and puts the actions you actually use one click away.

LOOKS LIKE YOUR SYSTEM
• Windows 11 (Fluent), macOS and Linux (GNOME) styles, picked automatically
• Light and dark themes, accent color, transparency, corner radius, font and animation
• Shortcut labels that match your keyboard (Ctrl on Windows and Linux, ⌘ on macOS)

SHORT BY DESIGN
• Compact layout: the main actions stay on top, the rest move into a "More" submenu
• Back, Forward, Reload and Print as one row of icons
• Pin favorites to the top, reorder, or switch off anything you never use

USEFUL ACTIONS
• Text: copy, search, translate, change case, word count, read aloud, copy as Markdown
• Links: open in a new tab (in the background or switching to it) or a private window, copy a clean link without tracking parameters, QR code, Wayback Machine
• Images: copy, save, search by image (Google Lens, Bing, Yandex, TinEye), extract text (OCR), read Stable Diffusion / ComfyUI prompt metadata
• Video: Picture-in-Picture, playback speed, loop, copy the current frame
• Page and developer tools: forced dark mode per site, screenshot, color picker, CSS selector, Tailwind classes
• Your own actions: open any URL template, or send the selection to your own AI model (LM Studio, Ollama, OpenAI-compatible)

PRIVATE BY DEFAULT
• No analytics, no tracking, no account
• Nothing leaves your browser unless you choose an action that needs a service (search, OCR, your AI endpoint)
• Settings sync through your browser account; API keys stay on this device

Works in Chrome, Edge, Opera, Brave and Firefox. Interface in English, Türkçe, Deutsch, Français, Español and Русский.
Shift + right-click always opens the browser's own menu, and text fields keep it for spelling and paste.

FluentContext Pro tarayıcının sağ tık menüsünü işletim sisteminize uyan, sade ve hızlı bir menüyle değiştirir. Gerçekten kullandığınız işlemler bir tık uzağınızda olur.

SİSTEMİNİZ GİBİ GÖRÜNÜR

Chrome, Edge, Opera, Brave ve Firefox'ta çalışır. Arayüz dilleri: English, Türkçe, Deutsch, Français, Español ve Русский.
Shift + sağ tık her zaman tarayıcının kendi menüsünü açar; yazı alanlarında yazım denetimi ve yapıştırma için tarayıcı menüsü korunur.
